# twit-fixer

literally just replaces twitter (otherwise known as X The Everything App) with vxtwitter links <br>
everybody deserves good links

## installation

just zip the FILES (not the parent folder) and replace zip with .xpi <br>
make sure `xpinstall.signatures.required` is false in `about:config` if on zen <br>
note: don't go around installing random extensions: signatures are there for good reason and you should only install from trusted sources <br>
